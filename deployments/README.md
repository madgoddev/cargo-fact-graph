# Deployment evidence

`studionet.json` is the current finalized CargoFactGraph v5 StudioNet deployment
and semantic-write record. `bradbury.json` is the current finalized v5 Bradbury
deployment and semantic-write record, including exact latest-final graph
readback.

`studionet-policy-v4.json` and `bradbury-policy-v4.json` are immutable historical
records for the exact v4 source identified inside each file. They are not v5
deployment evidence.
